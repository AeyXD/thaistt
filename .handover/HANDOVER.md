### ควรปรับปรุงต่อ (เรียงตามความสำคัญ — ยังไม่ได้แก้)

1. **batch เขียนผลลัพธ์ตอนจบทั้งงานเท่านั้น — "resume ได้" ยังไม่จริงสำหรับรันที่พังกลางทาง**
   (สำคัญที่สุดก่อนรัน W1 ~18k คลิป): `<stem>.txt` และ manifest ถูกเขียนหลังลูปทุกกลุ่ม
   (`run_batch` ~บรรทัด 1225–1231) ส่วนผลระหว่างทางอยู่ใน temp ที่ล้างทิ้งต่อกลุ่ม
   → Ctrl-C / ไฟดับ / whisper พังระดับงาน ที่ชั่วโมงที่ 1.9 = เสียผลทั้งหมด รันซ้ำเริ่ม
   จากศูนย์ (ขัดกับที่บันทึกไว้ข้างล่าง "resume ได้ — พังตรงไหนรันซ้ำต่อจากนั้น") ·
   เสนอ: เขียน `.txt` + อัปเดต manifest ท้ายแต่ละกลุ่ม · เทส: fake whisper พังที่กลุ่ม 2
   → กลุ่ม 1 ต้องมีผลและรอบถัดไปข้ามได้
2. **เขียน manifest แบบ atomic** — ตอนนี้เปิด `"w"` ตรง ๆ ถ้าพังกลางการเขียนไฟล์จะขาด
   และ `_read_manifest_rows` อ่านไม่ได้คืน `{}` เงียบ ๆ → รอบถัดไปเขียนทับประวัติทั้งหมด
   (ขัดหลัก "อนุรักษ์ข้อมูลเดิม") · เสนอ: เขียน temp ในโฟลเดอร์เดียวกัน + `os.replace` ·
   อ่านเดิมไม่ได้ → เก็บสำรอง `.bak` + เตือน แทนทิ้งเงียบ — ควรทำพร้อมข้อ 1
   (เขียนถี่ขึ้น = โอกาสพังกลางเขียนมากขึ้น)
3. **แถวเดิมใน manifest ไม่ถูกคำนวณ `suspicious` ใหม่** — แถวจาก v0.3–v0.5 ใช้เกณฑ์เก่า
   (ไม่รวม avg_p<0.70) · เสนอ: คำนวณใหม่จาก duration_s/avg_p/lang_mismatch + อ่าน
   ข้อความจาก `<stem>.txt` (วลีหลอนต้องใช้ข้อความ) ตอนรวมแถว
4. **id = ชื่อไฟล์ไม่รวมนามสกุล ข้ามรอบ** — ในรอบเดียวกันกันชื่อชนไว้แล้ว แต่ต่างรอบจาก
   ต่างโฟลเดอร์ชื่อเดียวกันจะทับแถวกัน (และ resume จะข้ามเพราะ `.txt` ชื่อเดียวกัน) ·
   ของ W1/W2 ยังไม่เจอ (id ไม่ซ้ำทั้งเกม) — บันทึกไว้ในเอกสาร หรือเตือนเมื่อ `file` ของ
   แถวเดิมต่างจากไฟล์ที่ข้าม
5. **แถวค้างของไฟล์ผลที่ถูกลบ** — ลบ `<stem>.txt` เองแล้วไม่ได้รันคลิปนั้นอีก แถวเดิมยังอยู่ ·

## คำขอจาก ThaiW2Setup → v0.3 (2026-11-01 — ผู้ใช้ส่งต่อจาก W2 session, ลำดับตามที่ W2 จัด)

ใช้จริงกับเสียงพากย์ W2 (`voice_en.py collect` ใน ThaiW2Setup) — เรียงตามความคุ้ม: **ข้อ 1–3 ช่วยมากที่สุด**

**ควรทำก่อน**
1. **รับไฟล์ .mp2 / ไม่กรองด้วยนามสกุลอย่างเดียว** — เสียง W2 เป็น MPEG-1 Layer II แต่ต้องตั้งชื่อเป็น .mp3 เพื่อให้ thaistt รับ
   → เพิ่ม `.mp2` ใน MEDIA_EXTS (แก้บรรทัดเดียว) และ/หรือ `--any-ext` ให้ ffprobe ตรวจเนื้อไฟล์แทนนามสกุล
2. **ไฟล์สรุปผลแบบเครื่องอ่านได้** (`manifest.csv` หรือ `--json`) — ต่อคลิป: ไฟล์ / ความยาวเสียง (วินาที) / สถานะ
   (สำเร็จ ว่าง พัง ข้าม) / ป้ายคลิปน่าสงสัย — ตอนนี้ป้ายพิมพ์ออกจอเท่านั้น ฝั่งเกมต้องคำนวณความยาวเอง (W2 เดาจากขนาดไฟล์ CBR)
   และไม่รู้ว่าคลิปไหนถูกติดป้าย
3. **ค่าความมั่นใจต่อคลิป** (เช่น avg logprob จาก whisper.cpp) — บรรทัดที่ Whisper ฟังผิด (บทนำ W2 มี 35 บรรทัด) จะได้ส่งไปตรวจก่อน
   หรือกันไม่ให้ผู้ช่วยแก้ซับตามข้อความที่ถอดผิด (เช่น "Echeveru" = Etcheverry ที่ผู้แปลเดิมแปลว่า "ช่างโหดร้าย")

**ช่วยให้สะดวกขึ้น**
4. **เตือนความยาวคำใบ้** — whisper ใช้ prompt ได้ราว 224 token ส่วนเกินถูกตัดทิ้งเงียบ ๆ → รายงานจำนวน token หรือตัดให้เอง
   โดยเก็บชื่อต้นไฟล์ไว้ (ตอนนี้ W2 ต้องจำกัดเองที่ 900 ตัวอักษร)
5. **รับรายการไฟล์** (`--files-from list.txt` หรือ stdin) — ถอดเฉพาะ id ที่เลือก โดยไม่ต้องแตกเสียงแยกโฟลเดอร์ทุกองก์
6. **`--force` / `--redo-from list.txt`** — ถอดซ้ำเฉพาะคลิปที่ต้องการ (เช่น หลังเพิ่มชื่อใน prompt แล้วถอดบรรทัดที่ชื่อเพี้ยนใหม่)
   — ตอนนี้ข้ามคลิปที่มีผลแล้ว ต้องลบไฟล์ผลเองก่อน

**ถ้ามีเวลา**
7. **ถอดหลายภาษาในรอบเดียว** (`-l en,pl` แยกโฟลเดอร์ผล) — W2 มีเสียงโปแลนด์ (pl0.w2speech = ต้นฉบับอ้างอิง) ถอดทั้ง en และ pl
   ในคำสั่งเดียว จะเทียบเสียงโปแลนด์กับคำแปลได้ตรงขึ้น
8. **VAD / ข้ามคลิปเงียบ** — กันข้อความที่ Whisper แต่งเองบนเสียงสั้น/เสียงร้อง เช่น "Thank you." บนคลิปเงียบ
   (ซ้ำกับข้อเสนอ W1 ข้อ 2 ด้านบน)
